# GW2 Visualizer

*Unofficial fansite — not affiliated with ArenaNet or NCSOFT.*

Search any Guild Wars 2 item and explore its full crafting tree as an interactive graph: pan, zoom, drag, hover for
details, and see what everything costs on the trading post.

## Quick start

Requires Node.js 20 or newer.

```bash
npm start
```

Then open http://localhost:8642. See [CHANGELOG.md](CHANGELOG.md) for what's new.
